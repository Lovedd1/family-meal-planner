# 点餐页面交互优化设计

## 需求
1. 菜品分类改为左侧边栏（参考美团点餐）
2. 早午晚餐选择改为添加菜品时底部弹出选择

## 布局结构

```
+-----------------+------------------------+
|                 |      搜索框             |
|   分类侧边栏    |------------------------|
|                 |      菜品列表            |
|  · 全部         |   ┌─────────────────┐  |
|    荤菜         |   │  🍲 番茄炒蛋     │  |
|    素菜         |   │  加热 | 食材...  │  |
|    主食         |   └─────────────────┘  |
|    汤品         |   ┌─────────────────┐  |
|                 |   │  🍖 红烧排骨     │  |
|  160rpx         |   └─────────────────┘  |
+-----------------+------------------------+
```

## 侧边栏样式（美团式）
- 宽度：160rpx
- 背景：浅灰粉色 #F5F0F0
- 当前选中：左侧4rpx高亮条（#C48B8B）+ 白色背景 + 圆角
- 文字：居左居中，28rpx，深色 #5D4A4A
- 分类项高度：100rpx

## 添加菜品交互
1. 点击菜品卡片任意位置
2. 底部弹出餐次选择器：

```
┌─────────────────────────────────┐
│         选择添加到              │
│  ┌───────┐ ┌───────┐ ┌───────┐│
│  │🌅早餐 │ │☀️午餐 │ │🌙晚餐 ││
│  └───────┘ └───────┘ └───────┘│
│                                 │
│         ── 取消 ──              │
└─────────────────────────────────┘
```

## 改动范围

### order.wxml
- 结构调整：分类侧边栏 + 右侧内容区分栏布局
- 顶部餐次选择栏（add-to-bar）移除
- 菜品点击改为弹出餐次选择器
- 自定义菜品按钮保留在列表顶部

### order.wxss
- 新增侧边栏容器样式（左侧固定，右侧flex1）
- 新增侧边栏分类项样式（美团式选中效果）
- 新增底部弹窗样式（底部弹出选择器）
- 移除 add-to-bar 相关样式

### order.js
- `addToMenu` 改为弹出选择器而非直接添加
- 新增 `showMealTypePicker` 方法显示底部弹窗
- 新增 `selectMealType` 方法处理餐次选择
- 移除 `switchTab` 方法（不再需要顶部餐次切换）
- `isAdded` 方法保留，用于显示菜品是否已在某餐中
