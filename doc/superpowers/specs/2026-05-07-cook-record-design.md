# 做饭记录功能重设计方案

## 1. 设计目标

**核心理念**：像翻照片墙/日记一样，回味每道菜的故事

**设计方向**：故事流卡片 —— 强调"记录"与"回顾"的温度感，而非效率

---

## 2. 整体结构

### 2.1 页面组成

| 页面 | 类型 | 说明 |
|------|------|------|
| 主页 | 照片墙瀑布流 | 展示所有做饭记录，按月份/周数分组 |
| 详情页 | 全屏页面 | 点击卡片进入，展示大图+完整信息 |
| 编辑页 | 全屏页面 | 新增/补录记录，编辑已有记录 |

## 3. 卡片设计

### 3.1 卡片样式

```
┌─────────────────────┐
│                     │
│    [照片/图片]       │  ← 4:3 比例，圆角 12rpx
│                     │
├─────────────────────┤
│ 🍖 红烧排骨          │  ← 菜品 emoji + 名称
│ ⭐⭐⭐⭐             │  ← 评分星星
│ "今天的肉很嫩！"     │  ← 一句话备注（截断显示）
│ 5月3日 · 午餐        │  ← 日期 + 餐次
└─────────────────────┘
```

- 卡片背景：白色
- 圆角：16rpx
- 阴影：0 2rpx 12rpx rgba(0,0,0,0.05)
- 照片比例：4:3（统一美观）
- 最小高度：240rpx

### 3.2 空状态

```
┌─────────────────────────────────────┐
│                                     │
│              🍳                      │
│                                     │
│         还没有做饭记录                │
│     点击下方按钮记录第一道菜          │
│                                     │
└─────────────────────────────────────┘
```

## 4. 详情页（全屏页面）

### 4.1 布局

```
┌─────────────────────────────────────┐
│ ← 返回                    ··· 更多  │  ← 导航栏
├─────────────────────────────────────┤
│                                     │
│                                     │
│         [大图展示]                   │  ← 可左右滑动
│                                     │
│                                     │
├─────────────────────────────────────┤
│ 🍖 红烧排骨           ⭐⭐⭐⭐⭐     │  ← 菜品 + 评分
│ 2026年5月3日 · 12:30 · 午餐         │  ← 时间线信息
├─────────────────────────────────────┤
│ 备注                                 │
│ 今天尝试了新的炒糖色方法，肉的颜色     │
│ 特别漂亮！下次可以少放点酱油。        │

├─────────────────────────────────────┤
```

### 4.2 功能

- **图片浏览**：大图展示，支持左右滑动翻看同一月的记录
- **信息展示**：菜品名、评分、时间、餐次、完整备注
- **更多菜单**：删除记录（需确认）
- **编辑入口**：进入编辑页修改记录

### 5.2 交互规则

| 字段 | 规则 |
|------|------|
| 图片 | 必填，点击可从相册选择或拍照更换 |
| 关联菜品 | 必填，搜索 + 网格选择，已选项高亮显示 |
| 餐次 | 必填，早餐/午餐/晚餐单选 |
| 评分 | 可选，1-5星 |
| 备注 | 可选，最多200字 |

### 5.3 验证逻辑

- 图片未选择：提示"请先选择图片"
- 菜品未选择：提示"请选择关联菜品"
- 餐次未选择：提示"请选择餐次"
- 保存后自动返回主页并刷新

## 6. 数据结构

### 6.1 存储字段

```javascript
// 做饭记录 (cookingRecords)
{
  id: String,              // 唯一ID，格式: cr_timestamp_random
  date: String,            // 记录日期，格式: YYYY-MM-DD
  meal: String,            // 餐次: breakfast/lunch/dinner
  imagePath: String,        // 图片本地路径
  menuItemId: String,      // 关联菜品ID
  menuItemName: String,    // 关联菜品名称
  emoji: String,           // 菜品emoji
  rating: Number,          // 评分 1-5，0表示未评分
  notes: String,            // 备注
  createdAt: Number,       // 创建时间戳
  updatedAt: Number        // 更新时间戳
}
```

### 6.2 餐次枚举

```javascript
{
  breakfast: '早餐',
  lunch: '午餐',
  dinner: '晚餐'
}
```

## 7. 技术实现

### 7.1 文件结构

```
miniprogram/pages/cook/
├── cook.wxml      # 主页（照片墙）
├── cook.js
├── cook.wxss
├── cook.json
├── cook-detail/  # 详情页
│   ├── cook-detail.wxml
│   ├── cook-detail.js
│   ├── cook-detail.wxss
│   └── cook-detail.json
└── cook-edit/    # 编辑页
    ├── cook-edit.wxml
    ├── cook-edit.js
    ├── cook-edit.wxss
    └── cook-edit.json
```

### 7.2 路由

| 页面 | 路径 | 跳转方式 |
|------|------|----------|
| 主页 | /pages/cook/cook | tabBar 入口 |
| 详情页 | /pages/cook/cook-detail/cook-detail | navigateTo，传递记录ID |
| 编辑页 | /pages/cook/cook-edit/cook-edit | navigateTo，新增时无参数，编辑时传递记录ID |

### 7.3 存储

- 本地存储：使用 storageAdapter，统一管理
- 存储 Key：`cookingRecords`
- 数据格式：JSON 数组，按 createdAt 降序排列

## 8. 页面流程

### 8.1 新增记录

```
首页 [+] → 相册选择 → 编辑页 → [保存] → 返回首页刷新
```

### 8.2 查看详情

```
首页卡片 → 详情页 → [编辑] → 编辑页 → [保存] → 返回详情页刷新
```

### 8.3 删除记录

```
详情页 [···] → 删除确认 → 删除成功 → 返回首页
```

## 9. 与旧版对比

| 维度 | 旧版 | 新版 |
|------|------|------|
| 交互模式 | 弹窗式 | 全屏页面 |
| 图片选择 | 强制拍照 | 相册/拍照均可 |
| 菜品选择 | 二次弹窗，不确定是否选中 | 网格展示，已选高亮 |
| 备注编辑 | 输入后弹窗关闭 | 全屏页面，不影响 |
| 回顾体验 | 列表式 | 照片墙瀑布流 |
| 详情浏览 | 小图+弹窗 | 大图+可滑动 |
