# AI饮食计划生成 - 设计文档
**日期：** 2026-05-04
**状态：** 已完成设计

## 目标

用户点击"生成饮食计划"后，基于以下信息生成完整的阶段性饮食计划：
- 体重目标（减脂/维持/增肌）
- 活动水平（久坐/适度/运动多）
- 过敏食物
- 生理期状态（经期/卵泡期/排卵期/黄体期）

## 设计方案

### 1. 输入参数

| 参数 | 来源 | 说明 |
|-----|------|-----|
| dietGoal | 健康档案 | lose(减脂)/maintain(维持)/gain(增肌) |
| activityLevel | 健康档案 | sedentary(久坐)/moderate(适度)/active(运动多) |
| allergies | 健康档案 | 过敏食物列表 |
| currentPhase | 健康档案 | menstruation(经期)/follicular(卵泡期)/ovulation(排卵期)/luteal(黄体期) |
| targetWeight | 健康档案 | 目标体重 |

### 2. 输出内容

#### 阶段计划（3个阶段）

| 阶段 | 时长 | 热量 | 饮食重点 |
|-----|------|------|---------|
| 适应期 | 1-2周 | 1800-2000kcal | 调整饮食结构，逐步减少高热量食物 |
| 强化期 | 3-8周 | 1400-1600kcal | 严格控制热量，增加蛋白质摄入 |
| 巩固期 | 2-4周 | 1600-1800kcal | 稳定体重，养成健康饮食习惯 |

#### 每周菜单

每阶段包含多周菜单，每周内容：
- 每日三餐：早餐、午餐、晚餐
- 加餐：上午/下午/睡前
- 每道菜标注功效（如：补铁、消肿、促代谢）

#### 食材采购清单

**按每2天采购周期：**
```
第1批采购（2天量）：
- 鸡胸肉 500g × 2份 = 1kg
- 西兰花 300g × 2份 = 600g
- 鸡蛋 7个
- 糙米 500g
- 番茄 400g

第2批采购：
- 牛肉 400g × 2份 = 800g
- 土豆 500g × 2份 = 1kg
- 洋葱 200g
...
```

### 3. 生理期适配

根据当前生理期阶段调整饮食重点：

| 阶段 | 饮食重点 | 推荐食材 |
|-----|---------|---------|
| 经期 | 补铁为主 | 红枣、菠菜、动物肝脏、红豆 |
| 卵泡期 | 低脂高蛋白 | 鸡胸肉、鱼、豆腐、糙米 |
| 排卵期 | 优质蛋白+健康脂肪 | 鸡蛋、牛油果、坚果、三文鱼 |
| 黄体期 | 控制碳水、利尿消肿 | 冬瓜、西瓜、芹菜、绿茶 |

### 4. 食材提醒

当所需食材冰箱没有时，显示采购提示：
```
⚠️ 鸡胸肉 500g — 冰箱中没有，需要购买
✅ 西兰花 300g — 冰箱有200g，足够
```

### 5. 技术实现

#### 前端 (health.js)
- 点击"生成饮食计划"按钮
- 显示加载状态（wx.showLoading）
- 调用云函数获取AI建议
- 展示完整计划弹窗
- 保存到本地存储

#### 云函数 (generateDietPlan)
- 接收用户健康档案参数
- 调用DeepSeek API生成饮食计划
- 返回结构化JSON（阶段计划+菜单+采购清单）

#### API Prompt 设计

```
你是专业营养师，请为用户生成个性化饮食计划。

用户信息：
- 目标：{dietGoal}
- 活动水平：{activityLevel}
- 过敏食物：{allergies || '无'}
- 生理期阶段：{currentPhase}

请按以下JSON格式返回（必须严格遵守格式）：
{
  "phases": [
    {
      "name": "适应期",
      "duration": "1-2周",
      "calories": "1800-2000kcal",
      "focus": "调整饮食结构",
      "weeklyMenus": [
        {
          "week": 1,
          "days": [
            {
              "breakfast": {"name": "xxx", "effect": "xxx", "ingredients": ["xxx"]},
              "lunch": {"name": "xxx", "effect": "xxx", "ingredients": ["xxx"]},
              "dinner": {"name": "xxx", "effect": "xxx", "ingredients": ["xxx"]},
              "snacks": [{"name": "xxx", "time": "上午"}]
            }
          ]
        }
      ],
      "shoppingList": [
        {"name": "鸡胸肉", "amount": "1kg", "period": "2天"}
      ]
    }
  ]
}
```

### 6. 数据存储

- **dietPlan** — 生成的完整计划，存入 `wx.setStorageSync('dietPlan', plan)`
- **healthProfile** — 用户健康档案，持续更新

### 7. 错误处理

| 错误 | 处理 |
|-----|------|
| API调用失败 | 显示"生成失败，请重试"，不保存空数据 |
| 网络超时 | 30秒超时，显示超时提示 |
| 参数不完整 | 引导用户完善健康档案后再生成 |

2. 正确显示3个阶段的切换Tab
3. 每周菜单显示早中晚+加餐，标注功效

6. 生理期阶段正确影响推荐内容
