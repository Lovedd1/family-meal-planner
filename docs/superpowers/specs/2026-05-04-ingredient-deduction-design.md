# 食材扣减逻辑 - 设计文档
**日期：** 2026-05-04
**状态：** 已完成设计

## 目标

当用户确认今日菜单后，扣减冰箱中对应食材的库存。部分扣减，不足时提示用户需要补充的数量。

## 设计方案

### 1. 数量解析函数

解析食材字符串，提取数字和单位。

**支持格式：**
- `200g` → `{ value: 200, unit: 'g' }`
- `3个` → `{ value: 3, unit: '个' }`
- `500g` → `{ value: 500, unit: 'g' }`
- `1份` → `{ value: 1, unit: '份' }`

### 2. 累加同种食材

多道菜需要同种食材时，累加所需数量。

**示例：**
- 早餐：番茄炒蛋（需要番茄200g）
- 午餐：番茄牛肉汤（需要番茄200g）
- 晚餐：土豆炖牛肉（需要土豆200g）

**结果：** 番茄需要400g，土豆需要200g，牛肉需要250g

### 3. 部分扣减逻辑

```
冰箱有库存 → 扣减到0为止
冰箱不足 → 扣减全部库存，提示"需要补充X"
```

**示例：**
- 需要鸡蛋4个，冰箱有2个 → 扣减2个，提示"需要补充2个鸡蛋"
- 需要土豆200g，冰箱有50g → 扣减50g，提示"需要补充150g土豆"

### 4. 扣减结果展示

确认弹窗显示扣减清单：

```
✅ 土豆 -200g（剩余0g）
✅ 牛肉 -150g（剩余50g）
⚠️ 鸡蛋 -4个（需要补充2个，冰箱只有2个）
```

**标记含义：**
- ✅ 库存充足，扣减成功
- ⚠️ 部分扣减，需要补充

### 5. 数据更新

扣减成功后，更新 `fridgeItems` 存储：
- 库存减为0的食材，保留记录（带0库存标记）
- 库存不足的食材，标记"需要补充"
- 用户下次进入冰箱页面时看到预警
